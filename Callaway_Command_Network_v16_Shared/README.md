# Callaway Command Network — V16 Shared Parent/TV Edition

V16 separates the project into:

- `docs/` — public GitHub Pages site
  - `index.html` = classroom TV view
  - `parent.html` = parent/family view
  - `shared-content.json` = the one published data file both views read
- `instructor/` — local instructor editor

## Instructor workflow
Open `START_INSTRUCTOR_EDITOR.bat`, edit the display, then click **Download Shared Update**. Upload/replace `docs/shared-content.json` on GitHub. The same update then appears on the classroom TV and parent link.

See `GITHUB_PAGES_SETUP.md` for deployment steps.
